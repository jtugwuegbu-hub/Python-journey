There are many programming languages in the world, some of the famous one's are python,java
C,C++,C#,javascript etc. Python is considered one of the easy programming languages to learn and use
as it provides a good natural language like syntax and a well supported library,
which you just need to import with a single line of python code.

and as the saying goes, practice makes perfect.If your python program isn't running,
just make sure you haven't made any syntax mistakes, have all the indentation correct and haven't made any str to int
